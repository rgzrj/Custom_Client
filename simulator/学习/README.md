# 模拟裁判系统学习路线

本项目不涉及网页前端；你可以先把它当作给视觉和操作手客户端提供输入的可控数据源。

从 [第 5 阶段：模拟器与联调](05-模拟器与联调.md) 开始，它沿用原学习路线编号，不要求先学 QML。

1. 启动两个独立窗口，确认 Python 控制台只负责发数据。
2. 修改红蓝车辆和本车状态，追踪 `simulator/sim_state.py` 中的同源载荷。
3. 区分本地回放、探针与实际 TS 发包，再测独立断流。
4. 一次只注入一种网络故障，观察接收端而不是只看设置值。
5. 保存场景与记录，回放问题，再运行本项目回归测试。

命令均从 simulator 项目目录执行，详细步骤见 [README.md](../README.md)，安全与日志要求见 [CLAUDE.md](../CLAUDE.md)。
