# 自定义客户端协作说明

修改本仓库前，必须完整阅读并遵守 `CLAUDE.md`。

每完成一组仓库修改，都必须在 `Edit.md` 末尾追加带时间戳的记录，包含修改路径、摘要、验证结果和规则/协议来源。

- 本目录是独立 Qt/QML/C++ 项目，所有相对路径以本目录为起点。
- 修改前说明假设与验证计划；不明确的规则或协议不得猜测。
- 只修改本次任务涉及的内容，保留用户已有工作，不做顺带重构。
- 优先复用现有实现、标准库和 Qt 能力，不添加无需求的架构或依赖。
- 从本目录构建和运行；不得依赖父目录的构建文件、启动器或 Python 模拟器代码。
- 跨项目任务须分别阅读各项目的 CLAUDE.md，分别记录日志；不要将模拟器日志继续记入本项目。
- `Edit.md` 仅本机保存，不提交 Git、不随发布包分发。旧历史不改写，只追加。
- 协作入口使用标准文件名 `AGENTS.md`，以便工具自动识别。
