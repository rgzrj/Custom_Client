# 第 4 阶段：视频怎样进入窗口，延迟到底测什么

预计 3 次，每次 30～45 分钟。你做 CV，可以从视频链路入手：先区分“收包、解码出帧、呈现、控制安全”，再看 UI 对象。不要把一个模拟数字当成系统已经低延迟的证据。

## 第 1 次：本地视频路径

读 [Qt 官方中文 VideoOutput](https://doc.qt.io/qt-6/zh/qml-qtmultimedia-videooutput.html) 的 videoSink、fillMode 和 clearOutput，再读 [QVideoSink](https://doc.qt.io/qt-6/zh/qvideosink.html) 的 videoFrameChanged。先掌握用途，不要求会 Qt 的渲染实现。

看 [`qml/Main.qml`](../qml/Main.qml)：openLocalVideo 先停止旧源、清旧帧、切换回放模式，再设置 player.source 并播放；MediaPlayer 的 videoOutput 指向 VideoOutput。Qt Multimedia/FFmpeg 后端负责解码，HUD 是另外一层，不烧录到帧像素里。PreserveAspectFit 保留完整视野，非 16:9 视频会留边。

看 [`terminal_controller.cpp`](../src/app/terminal_controller.cpp) 的 observeVideoSink：有效帧到达时计数、更新时间、更新视频状态。这里的“收到解码帧”不等于已经测出相机采集到显示器发光的延迟。

练习：打开本地视频，播放、暂停、拖动、结束后再播，观察画面和“回放”标识；打开一个无效文件，确认没有旧画面误装成新画面。回放始终不能解锁真实控制。

## 第 2 次：两条 UDP 入口不是同一个东西

先看 [`contracts/模拟接口-v1.md`](../contracts/模拟接口-v1.md) 的端点表。

- 39002：[`udp_video_ingress.cpp`](../src/video/udp_video_ingress.cpp) 只统计探针收到的包与字节，不能从随机探针解码图像。
- 39003：显式启用 -SimUdpVideo 后，播放器读取本机 MPEG-TS 测试流；有效 H.264 TS 才会出帧。它不是官方 RM2027 分片协议。

分别启动客户端和模拟器控制台，选一个本机合法 H.264 .ts，按“启动联调”。切换视频暂停与恢复时保持裁判数据发送，再反过来停止裁判数据而保持视频发送。观察两种故障是否独立，恢复后控制仍锁定。

控制台的位置与按钮见[模拟器教程](../../simulator/学习/05-模拟器与联调.md)。也可在模拟器项目目录运行：

```powershell
D:\YOLOV8\python.exe simulator\stream_video.py video\console-h264-valid.ts --loop
```

样本仅存在本机 video 目录，不上传 Git。没有该文件就选你自己的合法 TS；随机字节、普通 MP4 改后缀不能替代 TS。H.264 已验证，H.265 暂未验证。

## 第 3 次：看懂指标，设计可信的实验

| 当前读数 | 表示什么 | 不表示什么 |
| --- | --- | --- |
| 模拟延迟 / 模拟丢包 | 模拟载荷中填写的展示数字 | 实际网络测量 |
| 探针缺口 / 静默 | 到达间隔与最近包年龄 | 官方序号丢包率、真实解码延迟 |
| 出帧率 | 1 秒窗口内有效 sink 帧次数 | 显示器刷新率或每帧延迟 |
| frameAgeMs | 最近有效解码帧距离现在多久 | 视频内容比现实落后多久 |
| 出帧恢复 | 宣布视频过期到下一有效帧，包含等待 | 恢复发送到出帧、端到端耗时 |
| GUI 抖动 | UI 定时器调度偏差诊断 | 解码耗时的直接测量 |

本机视频约 700 ms 无有效帧会标记过期。新恢复测量使用 QElapsedTimer 单调时钟，未知时为 -1；诊断明确显示“端到端未测”。发送端固定延迟/抖动/丢包注入是实验条件，发送器丢弃数也不是客户端实际丢包率。

真正测采集到显示的端到端延迟，需要采集与展示的可比较时间基准或拍摄同屏时钟等实验设计；正式传输未到位，暂不做虚假的精确结果。

验收：记录一次“停止视频 → 客户端过期 → 恢复出帧”，分别写实验条件、观测读数、未测项目。不要只报一个 ms 数字。已有 [`tests/test_video_playback.cpp`](../tests/test_video_playback.cpp) 的 simulationUdpVideo 用真实 TS 字节验证独立断流/恢复，仍不等于实机赛事链路验收。
