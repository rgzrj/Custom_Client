# 从计算机视觉到 RM27 终端：学习路线

这份路线按本仓库实际技术栈组织：**Qt 6 + QML 做界面，C++ 管状态和安全逻辑，Qt Multimedia 显示本地视频，Python 只负责模拟数据**。这里的“前端”是桌面 QML，不是网页；暂时不用先学 HTML、CSS 或 React。

按顺序学习：[第 1 阶段：看懂 QML 界面](./01-QML入门.md) → [第 2 阶段：布局与视觉](./02-布局与视觉.md) → [第 3 阶段：C++ 与 QML 数据桥](./03-C++与QML数据桥.md) → [第 4 阶段：视频与低延迟](./04-视频与低延迟.md)。也可以先动手做 [第 5 阶段：模拟器与联调](../../simulator/学习/05-模拟器与联调.md)，它不依赖前端基础。第 6 阶段的系统教程尚未编写，先使用[发布验收清单](../packaging/验收清单.md)。

| 阶段 | 类别 | 学完能做什么 | 本仓库对应位置 |
| --- | --- | --- | --- |
| 1 | QML 基础与交互 | 读懂对象、属性绑定、点击事件，知道画面由哪些层组成 | `qml/Main.qml`、`qml/HudOverlay.qml` |
| 2 | 布局与视觉 | 调整 HUD、透明度、锚点、响应式尺寸，不挤占图传 | `qml/HudOverlay.qml`、`qml/OperatorCamera.qml` |
| 3 | C++ 与 QML 数据桥 | 追踪一个裁判数据字段如何变成界面文字和颜色 | `src/app/main.cpp`、`src/app/terminal_controller.*` |
| 4 | 视频与低延迟 | 区分本地回放、摄像头预览、待接入的正式图传 | `qml/Main.qml`、`src/video/` |
| 5 | 模拟器、测试与规则边界 | 自己制造状态变化、验证过期清空，区分模拟字段与官方协议 | 相邻独立模拟器项目、`tests/`、`CLAUDE.md` |
| 6 | 构建与交付 | 理解 CMake、Qt 组件、运行库和 Windows 发布 | `CMakeLists.txt`、`scripts/run-terminal.ps1` |

本目录的代码路径以 client 项目为起点。模拟器教程由模拟器项目独立维护，客户端自身运行不要求该项目存在。

学习方式：每阶段读少量中文原文，马上回到当前项目找对应代码，再用一个小练习验收。前两阶段都不需要修改正式控制、协议或视频接收代码。
